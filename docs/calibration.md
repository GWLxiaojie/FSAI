# ADS-DV 参数来源与实车验证

`ads_dv` 是官方 ADS-DV 几何参数加 EUFS 参考动力学的可运行基准，尚未完成实车标定。
`reference_bicycle` 保留原始参考用途。软件测试、成功启动和 CSV 门限通过均不自动改变
`reference_unvalidated`；工具也不会改写任何车辆 profile。

## 官方资料与缺口

依据官方 [Specifications & Dimensions v1.0 (2026-04-04)](https://github.com/FS-AI/FS-AI_ADS-DV_Documentation/blob/bb8f1624936f13c10a3406ea060088f2ffb4b908/FS-AI%20ADS-DV%20Specifications%20%26%20Dimensions.md)，
核对日期 2026-09-21，固定提交 `bb8f1624936f13c10a3406ea060088f2ffb4b908`。
这里固定版本方便复现；更换车辆年份、配置或官方资料版本时需要重新核对。

| 参数 | ADS-DV 基准 | 证据与状态 |
| --- | --- | --- |
| 轴距 | 1.53 m | 官方 1530 mm，`official_spec` |
| 前/后轮距 | 1.20 / 1.20 m | 官方各 1200 mm，`official_spec` |
| 驱动形式 | 后驱、开放式差速器 | 官方给定；前轴驱动扭矩上限为零 |
| 轮胎 | Toyo Proxes R888R 225/45 R13 84V | 官方型号；不等于已知有效滚动半径或侧偏刚度 |
| 电机/皮带 | 峰值 55.7 N m、传动比 3.5:1 | 官方给定，但不能直接确定车辆总后轴扭矩能力 |
| 质量/偏航惯量 | 300 kg / 172.44 kg m² | 沿用 EUFS 推算，`reference_unvalidated`；上述官方规格未给出 |
| 前轴静载比例/有效半径 | 0.5 / 0.2525 m | 沿用参考值，待称重/滚动测量 |
| 后轴/制动扭矩上限 | 各 393.9 N m | 原模型由 5.2 m/s² 推算，非官方轴端能力 |
| 轮胎、气动、阻力、执行器动态 | 参考参数 | 需要实测；官方几何不能证实这些参数 |

`55.7 × 3.5 = 194.95 N m` 仅是单台电机峰值经理想传动换算的算术结果；电机数量、
控制器限流、效率、转速/电压约束和轴端扭矩定义尚需核对，因此未据此替换后轴上限。
`official_spec` 表示静态资料有出处，并不表示整车模型通过动态验证。
profile 的 `valid_min/max` 是配置容许域，不是测量置信区间。

官方 [CAD](https://github.com/FS-AI/FS-AI_ADS-DV_CAD) 说明其模型仅包含整车的一部分，
不能据其几何外形推定完整质量/惯量；仓库未复制其受限 CAD 资产。
[FS-AI_API](https://github.com/FS-AI/FS-AI_API) README 的 `simulate` 模式说明数据不代表实车行为，
不能拿来标定。API 年份、CAN 比例/符号与本车固件版本须在采集时单独记录。

## CSV 评估入口

仅依赖 Python 3 标准库，从仓库根目录运行。模板只有表头，没有虚构测量数据：

```bash
python3 tools/calibration/evaluate.py template \
  --signals speed_mps yaw_rate_radps steering_rad > measured.csv
```

将实车和同一试验输入重放的模拟结果分别导出为 CSV。列顺序不限，但两份文件均须包含
`time_s` 和所有选定信号。允许额外数值列；全部列必须数值有限、非空，表头不得重复，
每行字段数必须正确，时间必须严格递增，每份至少两行。不要混入文字元数据列。

| 列 | 单位与定义 |
| --- | --- |
| `time_s` | 秒；共同试验基准下的采样时间，不能混用 wall time 与 ROS sim time |
| `speed_mps` | m/s；质心车体系纵向有符号速度 u，正方向向前，非速度模长或未经校准的轮速 |
| `lateral_speed_mps` | m/s；质心车体系横向速度 v，左为正 |
| `yaw_rate_radps` | rad/s；逆时针为正 |
| `steering_rad` | rad；等效道路轮转角，左为正，非方向盘角或未经映射的电机角 |
| `accel_x_mps2` | m/s²；质心物理纵向加速度 `u_dot - r*v` |
| `accel_y_mps2` | m/s²；质心物理横向加速度 `v_dot + r*u` |

IMU 应先补偿重力、安装姿态、外参与杆臂；车体轴系须统一为 x前、y左、z上。
RPM、rps、rad/s、km/h 必须在导出时明确转换，记录转换方式和轮径来源。
原始日志、命令、转换脚本、车辆配置、固件、轮胎温压、载荷和试验条件另存试验目录。

下面门限仅为命令示例，需由车队按控制用途和传感器精度预先确定：

```bash
python3 tools/calibration/evaluate.py evaluate \
  --measured measured.csv --simulated simulated.csv \
  --signals speed_mps yaw_rate_radps steering_rad \
  --max-rmse speed_mps=0.2 --max-error speed_mps=0.5 \
  --max-rmse yaw_rate_radps=0.03 --max-error yaw_rate_radps=0.1 \
  --max-rmse steering_rad=0.01 --max-error steering_rad=0.03 \
  --min-coverage 1.0 --report validation.json
```

模拟值在实测时间点上做线性插值，仅比较共同时间范围，绝不外推。
不同采样率可直接比较。`--sim-time-offset-s -10` 表示将模拟时间戳整体减 10 秒，
用于已知时钟原点差；不会按最优误差自动平移，也不消除真正的执行器/传感器延迟。
必须通过共同触发事件/同步时钟确定偏移并记录依据。

输出包括各信号 RMSE、最大绝对误差、单位、输入 SHA-256、偏移、门限、违反门限原因、
共同时间长度/比例、实测样本覆盖比例、实际比较首末时间和两份数据最大采样间隔。
RMSE 对比较到的每个实测样本等权，非时间积分加权；密集采样段权重更高。
共同时间覆盖比例以实测完整时长为分母，默认要求 100%；`--min-coverage` 可显式降低。
采样间断会被线性连接：必须检查最大采样间隔并按实际带宽选取记录频率，数据丢包严重时应先分段处理。
不适用于未展开的航向角或离散状态；这些字段未列入支持信号。

退出码：0 表示指定门限通过；1 表示门限/覆盖失败（仍写报告）；2 表示数据/参数/文件错误
（不写本次报告，旧报告可能仍存在，调用者必须检查退出码）。未指定误差门限时仅评估指标与覆盖，
`error_thresholds_configured` 为 false；即便输出 PASS，也不能称为精度验收通过。
报告始终为 `reference_unvalidated`，不会从一场试验推断整车标定状态。

## 实车补充数据与试验

| 试验/测量 | 必需量 | 可检验内容 |
| --- | --- | --- |
| 静态测量 | 本车带实际设备质量、四角轴荷、轴距、轮距、质心位置/高度、偏航惯量及方法 | 几何、静态载荷和惯量来源 |
| 轮胎滚动 | 地面独立速度/距离、各轮角速度、载荷与胎压 | 有效滚动半径；区分几何外径与负载半径 |
| Coast-down | 同步车速、时间、道路坡度、风、零驱动/零制动确认、质量 | 滚阻和空气阻力趋势；双向重复以识别坡度/风影响 |
| 直线加减速 | 驱动轴扭矩或经过校准的电流映射、制动压力/请求、车速、加速度、电池状态 | 驱动/制动映射、再生退出、制动合成和停车保持 |
| 低速/稳态圆周 | 转角命令与实际道路轮角、u/v、偏航角速度、半径、胎压/温度 | 转向映射、低速几何与不同车速的侧向稳态响应 |
| 转向阶跃 | 同步输入与实际道路轮角、偏航响应，多个幅值/方向/速度 | 死区、速率上限、纯延迟、一阶近似是否适用 |
| 传感器独立标定 | 真值参考、外参、原始时间戳、噪声/延迟与丢包记录 | 外参、频率、延迟、噪声，区别传感器误差与动力学误差 |

此工具只评估误差，不自动拟合阻力或一阶转向参数：未核对坡度、风、执行器限幅和时间同步前，
自动拟合容易把其他误差吸收到参数中。补齐实测后，可新增有试验条件约束的拟合模块。
应分开参数辨识数据与留出验证数据，记录重复试验波动/测量不确定性，逐信号、逐工况设门限。

验证报告旁应附试验 ID、日期、车辆/参数 hash、代码版本、原始日志来源、预先约定门限、
速度区间、转角/加速度区间、路面、胎温/胎压、载荷、电池状态、时间同步方法以及未通过项目。
现阶段没有实车数据，因此没有声明任何已验证速度范围。动态自行车的左右轮速、联合滑移和载荷转移
简化，限制了对 ABS、牵引控制、极限过弯和紧急制动转向的结论；通过直线试验不代表这些工况有效。

## 工具自检

```bash
python3 -m unittest discover -s tools/tests -p test_calibration.py -v
```

测试使用合成已知信号，覆盖时间偏移/不同采样率、已知误差、失败门限、覆盖不足、无时间重叠、
缺失/非有限/乱序数据和输入文件保护。它证明评估工具的行为，不是实车模型验证结果。
