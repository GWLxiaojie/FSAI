# 官方外观与10圈参考自检

## 本机启动

```bash
cd /home/muhan/ymh_data/FSAI/ads-dv-simulator
./tools/run_official_laps.sh
```

默认打开 RViz，自动进入 READY，等待5秒仿真时间后起步，以2.5 m/s巡航完成10圈并停车。实时运行约49分钟；转弯和终点前会调整车速。

```bash
./tools/run_official_laps.sh --fast
./tools/run_official_laps.sh --no-gui
./tools/run_official_laps.sh --fast --report artifacts/my-new-run.json
```

`--fast` 关闭窗口、按最快速度推进同一物理过程，本机一次完整仿真约12秒（不含首次下载/构建，耗时依硬件而异）。`--no-gui` 保持实时但关闭窗口。报告不覆盖已有文件；默认文件名包含UTC时间和进程号。
首次运行需要联网下载约数MB的锁定资源，之后校验本地缓存；每次启动会增量构建。新机器应先按 README 安装 Ubuntu 22.04 / ROS 2 Humble 依赖。

默认 `ROS_DOMAIN_ID=183 ROS_LOCALHOST_ONLY=1`，可通过环境变量覆盖；同目录同domain的一键入口拒绝重复启动。该锁不能防止你手动在同domain启动其他节点，所以录制/观察可以加入，但不要额外启动模拟器或控制器。
关闭 RViz 或 Ctrl-C 会中止实验，不算10圈通过。没有图形会话时使用 `--fast` 或 `--no-gui`，不需要伪造 DISPLAY。

## 官方来源与转换边界

来源为 [IMechE FS-AI 官方 HiL 仓库](https://github.com/FS-AI/FS-AI_IMechE_ADS-DV_HiL/tree/1fe77bed411ba621a3187bc2eb9ca13c7d371832)，固定提交 `1fe77bed411ba621a3187bc2eb9ca13c7d371832`。`simulator/official_assets.lock.json` 记录14个文件的路径、大小与Git对象哈希，下载后逐一校验。
这里接入的是官方仓库提供的 **Sprint/LTS 布局**，不是已经确认比赛年份的赛事实测地图。用户指定年份后，需要再核对对应官方数据，不能只改地图名称冒充该年份。

- 赛道：`Data/Road/FS_autonomous_Sprint_LTS.rd5`、对应 `Data/TestRun` 和 `Movie/3D/Terrain/FS_autonomous_Sprint_LTS.obj`。
- 车辆：`MovieNX/data/3D/Vehicles/Components/FSAI_RaceCar/FSAI_Body.glb`、`FSAI_Wheel.glb`；装配依据 `FSAI_RaceCar_2026.assetinfo`。
- 锥桶：官方 `Movie/TrafficCones` 网格，位置和颜色来自 TestRun 的366个对象。

不猜测 CarMaker Road 的私有插值语义。导入器从官方地形网格的道路开口边界提取中心线，重采样为1459点；道路铺装宽约10 m，但**锥桶行驶走廊宽为4 m**，两者不能混用。

| 总长度差 | 0.140111939 m，约0.0192% |

原始地形保留全部顶点和面，只将不可移植的 IPG 材质换成中性材质；缺失的程序化路面按同一官方布局生成可视化铺装，不另画椭圆替代。

### 车辆外观，不更换动力学

原始 GLB 字节不变：车身7个图元组、12940三角面；单个车轮5个图元组、4568三角面，实例化四次。材质及内嵌图像保留，没有减面或方盒替换。
坐标转换为 ROS Z-up，车身相对现有CG地面参考点平移x=-1.3287 m。外观前/后轮安装x=2.093/0.557 m、y=±0.476 m、z=0.257 m，再减CG偏移；右侧轮胎按官方装配旋转。
这些 MovieNX 外观坐标与官方车辆物理配置/当前轮距参数存在差别，故明确只用于显示，不暗中修改物理参数。

本功能没有改动 `fsai_sim_core` 或 ADS-DV 物理配置，仍是当前动态自行车、按轴轮胎/制动/执行器模型。没有运行商业 CarMaker 动力学，也没有新增逐轮滑移、悬架或载荷转移。官方外观不意味着模型已经实车标定。

## 控制与验收含义

内部参考驾驶器每20 ms仿真时间读取真实车体状态，结合已知中心线进行跟踪及速度控制；完整车身包络用于保守赛道边界检查，不只检查CG。
圈数通过有序弧长进度计数，防止近邻路段误吸附、起点抖动或瞬移“刷圈”。控制中心线只是同一闭合路径旋转到车辆起步点，并插入该投影点；不改变赛道形状。
这是从起步位置起算的完整回路，不是官方赛事计时线/罚时/锥桶碰撞裁定。

10圈后制动，并要求持续停稳才写完成报告。越界风险、非法进度或3600秒超时触发制动并失败退出。
`tools/check_lap_report.py` 检查10圈、完成状态、最终速度低于0.02 m/s、最小保守余量非负、最大横向误差不超过0.5 m及有限数值。命令返回成功意味着这些自动验收条件通过；中途终止不能通过。
报告包含参数哈希、中心线哈希、seed、圈数、误差、余量、仿真时长及结果。资源来源、转换假设和输出哈希位于 `.dependencies/official/generated/asset_manifest.json` 与 `track/provenance.json`。

**不将其称为完整无人驾驶验收**：驾驶器使用真值，不经过感知、定位、规划链。实车参数、赛道转换误差、传感器性能及比赛规则需独立验证。
